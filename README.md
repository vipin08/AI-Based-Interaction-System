# AI-Based Interaction System

An AI chat app with a modern UI, voice input, conversation memory, and personalized responses.

## Main Features
- Chat interface with AI responses
- Voice input using Web Speech API
- User profile and preferences
- Local and server-side conversation memory
- Responsive dark dashboard UI

## Main Setup
1. Go to the backend folder.
2. Install dependencies with `npm install`.
3. Add your API key in `backend/.env`.
4. Start the app with `npm run dev`.
5. Open `http://localhost:3000` in your browser.

## Project Folders
- `frontend` - UI files
- `backend` - server files and API routes
